# СТАРТ.SHOPIFY — бот продаж через Telegram Stars

Бот присылает бесплатный VSL-урок, затем предлагает купить полное 51-страничное
руководство за Telegram Stars (валюта `XTR`, платежи проходят прямо внутри Telegram,
без сторонних платёжных систем).

## Что делает бот

1. `/start` → приветствие → бесплатный VSL-урок (текст + PDF)
2. Оффер с кнопками «Купить гайд» и «У меня нет звёзд»
3. Кнопка «Купить» → выставляется счёт в Stars → оплата в 1 клик внутри Telegram
4. После оплаты бот сразу присылает полный PDF-гайд и логирует продажу в базу
5. Кнопка «Нет звёзд» → отправляет вашу реферальную ссылку на бота-обменник
6. `/myguide` — повторная выдача файла, если покупатель его потерял
7. `/stats` (только для админа) — сколько пользователей и продаж

## Шаг 1. Создание бота и получение токена

Если бота ещё нет:

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте `/newbot`, задайте имя и username (должен заканчиваться на `bot`)
3. BotFather пришлёт токен вида `123456789:AAExampleToken...` — скопируйте его

**Важно:** для приёма платежей Stars отдельно ничего подключать не нужно —
это встроенная функция Bot API, работает у любого бота автоматически.

## Шаг 2. Узнать свой Telegram ID (для уведомлений о продажах)

Напишите боту **@userinfobot** — он пришлёт ваш числовой ID.

## Шаг 3. Установка на сервере (VPS / любой Linux)

```bash
# 1. Скопируйте папку проекта на сервер (через scp, git, FTP — как удобно)

# 2. Установите Python 3.10+ (обычно уже есть на Ubuntu/Debian)
python3 --version

# 3. Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 4. Установите зависимости
pip install -r requirements.txt

# 5. Настройте переменные окружения
cp .env.example .env
nano .env   # впишите свой BOT_TOKEN и ADMIN_ID

# 6. Запустите бота
python bot.py
```

Если всё настроено верно, в консоли появится:
```
INFO:__main__:Бот запущен, ожидаю сообщения...
```

Откройте вашего бота в Telegram и отправьте `/start` — должен прийти free-урок и оффер.

## Шаг 4. Держим бота запущенным 24/7

Обычный `python bot.py` завершится, если закрыть терминал. Чтобы бот работал постоянно —
используйте `systemd` (рекомендуется) или `screen`/`tmux` для простоты.

### Вариант A: screen (быстро, для теста)
```bash
screen -S shopifybot
source venv/bin/activate
python bot.py
# Затем нажмите Ctrl+A, потом D — сессия свернётся, бот продолжит работать
# Вернуться в сессию: screen -r shopifybot
```

### Вариант B: systemd (надёжно, для продакшена)
Создайте файл `/etc/systemd/system/shopifybot.service`:

```ini
[Unit]
Description=Shopify Dropshipping Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/путь/до/папки/tgbot
ExecStart=/путь/до/папки/tgbot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Затем:
```bash
sudo systemctl daemon-reload
sudo systemctl enable shopifybot
sudo systemctl start shopifybot

# Проверить статус и логи:
sudo systemctl status shopifybot
sudo journalctl -u shopifybot -f
```

Бот будет автоматически перезапускаться при сбое и после перезагрузки сервера.

## Если ещё нет VPS

Простые и недорогие варианты для одного бота (не является рекламой, просто
для ориентира — сравните цены и условия сами перед выбором):
- Любой недорогой VPS с Ubuntu (от $3-5/мес)
- Хостинги с бесплатным тиром для небольших ботов (Railway, Render, Fly.io) —
  подходят для старта, но у бесплатных тарифов часто есть ограничения по времени
  работы или требуют настройки webhook вместо polling

Для этого кода используется **polling** (бот сам опрашивает Telegram) — это
самый простой вариант, не требует домена и SSL-сертификата, работает на любом
сервере с доступом в интернет.

## Изменение цены, ссылок и текстов

- Цена в Stars: переменная `PRICE_STARS` в `.env`
- Ссылка на бота-обменник звёзд: переменная `STARS_BOT_LINK` в `.env`
- Все тексты сообщений: файл `texts.py` — можно свободно редактировать
- Файлы PDF: замените файлы в папке `files/` на свои (сохраните те же имена
  или поменяйте пути в `.env`)

## Проверка платежей в тестовом режиме

Telegram позволяет тестировать Stars-платежи без реальных списаний через
специальный тестовый сервер ботов (`api.telegram.org` с тестовым токеном от
BotFather, команда `/newbot` в тестовой среде). Для большинства случаев проще
и быстрее протестировать напрямую на боевом боте минимальной суммой.

## Возврат средств (если понадобится)

Telegram поддерживает возврат Stars через метод API `refundStarPayment`
(user_id + telegram_payment_charge_id из таблицы `purchases` в базе данных).
Это не реализовано в боте по умолчанию — обращайтесь по мере необходимости
через отдельный скрипт или добавьте команду `/refund` при желании.
